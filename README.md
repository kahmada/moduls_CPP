  <ul>

    <li><strong>Module 01</strong>: Memory allocation, references, pointers</li>
    <li><strong>Module 02</strong>: Ad-hoc polymorphism, operator overloading</li>
    <li><strong>Module 03</strong>: Inheritance and interface design</li>
    <li><strong>Module 04</strong>: Abstract classes, sub-typing, dynamic casting</li>
    <li><strong>Module 05</strong>: Exceptions, try/catch, error handling</li>
    <li><strong>Module 06</strong>: File I/O and data streams</li>
    <li><strong>Module 07</strong>: Templates and generic programming</li>
    <li><strong>Module 08</strong>: Templated containers, iterators</li>
    <li><strong>Module 09</strong>: STL algorithms and containers</li>
